# IPL Match Winner Predictor

This project is an IPL Match Winner Predictor that Logistic Regression to predict the winner of a cricket match based on match features like wicket left, CRR, and participating teams.

## Features

- Data cleaning and preprocessing of IPL match records
- Handling categorical variables using Label Encoding
- Feature engineering using columns like team1, team2 etc
- Logistic Regression model training
- Evaluation using accuracy score and test split
- Model prediction to determine match winner based on current inputs

## Dataset

The dataset contains historical IPL match data including team names, match winners, toss results, venues, and other match-level metadata.
